# 日报助手 MVP 冒烟验收清单

## 环境

- 系统：Windows
- 启动命令：`npm run dev`

## 检查项

- [ ] 应用启动后不是空白屏。
- [ ] 默认进入「今日」页面。
- [ ] 左侧导航可以切换「今日」「时间线」「报告」「历史」「设置」页面。
- [ ] 暂停和继续记录按钮有响应，渲染进程没有报错。
- [ ] 设置页可以保存 MiniMax 提供方字段。
- [ ] 选择自定义 OpenAI-compatible 提供方时，未填写 Base URL 会提示错误。
- [ ] 设置页可以保存截图分析提示词和日报生成提示词。
- [ ] 生成日报后显示可编辑的 Markdown 内容。
- [ ] 复制日报操作可以保留当前报告内容。
- [ ] 在 1024x720 窗口下没有文字重叠或按钮文字溢出。
- [ ] 未手动开启前，截图上传给 AI 保持关闭。
